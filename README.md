# 소설 워드프로세서

소설가를 위한 웹 워드프로세서입니다. PC와 휴대폰 브라우저에서 열고, ‘홈 화면에 추가’(설치)하면 앱처럼 씁니다.

바로 쓰기: https://lussion629-creator.github.io/SOSUL-CHANGJAK-PROGRAM/

## 기능
- Word와 비슷한 서식: 굵게·기울임·밑줄·취소선, 글꼴·크기·색, 형광펜, 정렬, 목록, 제목 1~3, 인용, 장면 전환(* * *)
- **5초 자동 저장**: 손을 멈추고 5초 뒤 기기 안(IndexedDB)에 저장. 창을 닫거나 다른 앱으로 가도 즉시 저장
- **버전 기록**: 몇 분마다(1~30분, 설정 가능) 자동으로 버전이 쌓이고, 직접 이름 붙여 저장도 가능. ‘기록’ 탭에서 연·월·일을 골라 보고 되돌리기. 버전마다 바로 앞 버전에서 어디(몇 번째 문단, 원고의 어느 쯤)가 어떻게 바뀌었는지 자동 요약, 고른 기간 전체의 바뀐 내용 정리. 되돌리기 전 상태도 기록에 남음
- **퇴고 모드**: 이전 버전과 지금 원고를 나란히. 더한 곳 초록, 뺀 곳 빨강(문단·낱말 단위). 양쪽 각각 ‘페이지’(PDF처럼 A4 쪽) ↔ ‘본문/편집’ 전환, 바뀐 곳 표시 켜고 끄기, 함께 스크롤, 변경 목록에서 누르면 그 자리로 이동, 편집하면서도 바뀐 곳 표시
- **쪽 보기·쪽 설정**: 용지·여백·글꼴·자간·줄 간격·들여쓰기·쪽 번호를 정해 한 쪽씩 보면서 쓰기. 줄은 어절 단위(또는 글자 단위)로 나눔. 템플릿 저장·불러오기, 한글(hwpx) 파일에서 쪽 설정 가져오기. 기본 템플릿은 ‘소설 A5’(A5, KoPub바탕 Light 10pt, 자간 −8%, 줄 간격 180%). 내보낸 hwpx·docx·PDF에도 같은 쪽 설정이 들어감
- **글꼴·단락 창 (Word처럼)**: 원고에서 마우스 오른쪽 단추 → 글꼴…(Ctrl+D: 글꼴·크기·자간·색·굵게 등) / 단락…(Ctrl+Shift+P: 맞춤, 왼쪽·오른쪽 여백, 첫 줄 들여쓰기·내어쓰기, 줄 간격, 문단 위·아래 간격, 어절/글자 줄 나눔). 글자 크기는 0.5pt 단위(상자에 10.5처럼 넣기, −/+ 단추, Ctrl+[ / Ctrl+]). 한글·Word로 내보낼 때도 그대로
- **자간·줄 간격 (한글·Word 방식)**: 자간은 % (한글 방식) 또는 pt (Word 방식)로. 서식 도구 줄의 자간 칸에 -3 또는 -0.5pt처럼 넣거나 Alt+Shift+N/W로 1%씩. 글자를 고르지 않으면 커서가 있는 문단 전체에 적용(한 줄 넘친 문단 맞추기). 단락 창의 줄 간격은 비율(%) · 고정 값(pt) · 최소(pt) 중에서 고름
- **형광펜 색**: 형광펜 옆 ▾에서 노랑·연두·하늘·분홍·주황·보라·회색. Word로 내보내도 같은 색
- **본문 주석**: 글자를 고르고 마우스 오른쪽 → 색인 · 교정 제안 · 인용 · 의도 (Ctrl+Alt+M). 원고 옆 여백(오른쪽·왼쪽·숨김)에 카드로 보이고 ‘자료’ 탭에도 모임. 교정 제안은 ‘반영’ 한 번에 본문을 고치고(Ctrl+Z로 되돌리기) ‘거절’도 가능. 남긴 사람 이름이 붙어서 다른 사람이 같은 작품 파일(백업·드라이브)을 열어 교정을 남길 수 있음. 색인은 ‘찾아보기’에서 가나다순으로. Word로 내보내면 메모(댓글)로 들어감. ‘보기 → 주석 포스트잇’(Ctrl+Alt+P)을 켜면 원고 종이 가장자리에 쪽지처럼 붙어 보이고, 끌어서 옮기거나(오른쪽 단추: 처음 자리로) 접어 둘 수 있음
- **단축키 설정**: 도구 → 단축키 설정에서 기능마다 원하는 키로 바꾸기(겹치면 알려 줌, 기본값 되돌리기). 한글 입력 상태에서도 동작
- **원고 다듬기·인물 등장 지도·장 나누기**: 말줄임표·따옴표·여러 칸 띄어쓰기·문장부호 앞 빈칸·줄표를 한꺼번에 정리(바꾸기 전 상태는 버전 기록에). 자료의 인물·장소 이름(다른 이름 포함)이 장마다 몇 번 나오는지 표로. 커서 자리에서 장 나누기. 장마다 목표 분량과 진행 막대
- **실수 되돌리기**: 한 번에 많이 지우거나 모두 바꾸기를 하면 그 직전 원고를 ‘자동 보관’ 버전으로 남기고 바로 ‘되돌리기’ 단추를 띄움. 지운 장·작품은 휴지통에 30일 보관. 도구 → ‘실수 되돌리기·복구’에서 실행 취소, 최근 버전, 휴지통, 드라이브 백업을 한곳에서
- **장 이어서 전체 보기**: 보기 → 모든 장을 이어 ‘글만’ 또는 ‘쪽 모양’(쪽 번호 이어짐)으로 읽기, 차례로 가기, 문단을 두 번 누르면 그 자리로 가서 고치기
- **AI 낭독 (Gemini 목소리)**: 도구 → 낭독 설정에 Google AI Studio의 Gemini API 키를 넣으면 원고를 자연스러운 목소리로 읽어 줌(기본 모델 Gemini 3.8 Flash TTS, 다른 TTS 모델도 고를 수 있음). 목소리 30개 미리 듣기, 대사(따옴표 안)를 다른 목소리로, 읽는 분위기·연기 지시, 빠르기 0.75~2배, 장면 전환에서 쉬기, 읽는 문단 표시·따라 넘기기, 다음 장 이어 읽기, 다음 조각 미리 만들기, 요청 한도·서버 오류 때 자동 재시도, 만든 음성 저장(같은 글은 다시 요금 없음), 이번 달 사용량·예상 요금, 장·작품 전체를 WAV 음성 파일로 저장. 키가 없으면 기기 목소리로 읽음. 단축키 Ctrl+Alt+R(재생·멈춤), Esc(그만)
- **오늘 쓴 양**: 아래 상태 줄의 ‘오늘 쓴’을 누르면 직접 친 글자·붙여넣은 글자·합계를 따로 보고, 목표·그래프·연속 기록에 어느 쪽을 셀지 고르고(기본: 직접 친 글자만), 오늘 기록을 0부터 다시 셀 수 있습니다(되돌리기 가능). 이와 따로 ‘전날 대비 +N −M’은 오늘 처음 고치기 직전 원고(전날·지난번)와 지금 원고를 견준 순 변화라, 썼다가 그날 다시 지운 글자는 빠집니다
- **복사·붙여넣기 기록**: 원고에서 한 복사·잘라내기·붙여넣기·끌어 옮기기를 날짜별로 남깁니다(기록 → 복사·붙여넣기 기록). 종류·기간·내용으로 찾고, 붙여넣은 글을 본문에서 찾아 고르거나 다시 복사할 수 있습니다. 붙여넣은 글자는 쓴 양에서, 잘라내거나 붙여넣기로 덮은 글자는 지운 양에서 빼고 따로 세며, 전날 대비 +/−에서도 뺍니다
- **글자 색·형광펜 색**: 대표 색 견본에서 고르고, 다른 색은 ‘직접 고르기(RGB)’로 더하면 최근 색으로 남습니다. 오른쪽 클릭 메뉴에서도 형광펜 색을 고를 수 있습니다
- **작가용 도구**: 소리 내어 읽기(퇴고할 때 귀로 듣기), 표준국어대사전 찾기, 고른 글을 자료실 메모로, 고른 글자 수 표시, 왼쪽 목록 접기(Ctrl+\\)
- **여러 작품**: 제목 옆 책 단추로 다른 작품·글로 바로 바꾸기, 새 작품(제목 정하기), 드라이브에서 불러오기
- **다크 모드** / 밝게 / 종이색 / 기기 설정 따르기
- **파일**: 열기 docx · doc · hwpx · hwp · pdf · rtf · txt · md · html, 저장 docx · doc · hwpx · rtf · PDF(인쇄) · txt · md · html, 작품 백업(.novel.json). 연 문서는 모두 편집기에서 바로 고칠 수 있음
- **구글 드라이브 동기화**: 드라이브의 “소설 워드프로세서” 폴더에 작품마다 파일 하나(제목.novel.json.gz)를 두고 덮어씀. 압축하고 버전 기록은 달라진 문단만 담아 작게 올림. 정해 둔 간격(1·5·10·30분)과 창을 닫거나 다른 앱으로 갈 때만 올림. 다른 기기에서 이어 쓰기. 다른 기기에서 바뀐 내용을 받아 올 때 이 기기 내용은 버전 기록에 보관. 내보낸 Word 파일을 Google 문서로 바로 저장
- 소설가용: 장 목록(끌어서 순서 변경, 상태: 구상/초고/퇴고 중/완료, 장 줄거리), 코르크보드, 자료실(인물·장소·설정·사물·플롯/복선·메모, 등장하는 장 찾기), 글자 수(공백 포함/제외), **200자 원고지 매수**, 하루·작품 목표와 마감일, 연속 기록, **하루 기록 그래프**(날마다 쓴 양·고친 양·지운 양을 따로/쌓아서/합산해서, 7일·30일·90일·전체, 이 작품/모든 작품), 집중 모드(지금 문단만 밝게, 타자기 스크롤), 글쓰기 타이머(스프린트), 퇴고 도우미(자주 쓴 낱말, 습관어, 긴 문장, 대사 비율), 모든 장 찾기/바꾸기, 둥근 따옴표 자동 변환

## 보안·개인정보
- 원고는 이 기기(브라우저 저장소)와, 연결했다면 내 구글 드라이브에만 저장됩니다. 원고를 받는 서버나 데이터베이스가 따로 없습니다.
- 구글 드라이브는 이 앱이 만든 파일만 볼 수 있는 권한(drive.file)만 씁니다. 구글 OAuth 클라이언트 ID는 공개돼도 되는 값이고, 클라이언트 비밀번호(secret)는 쓰지 않습니다.
- 남이 만든 백업·문서 파일을 열 때 숨은 스크립트·이벤트·외부 주소를 걸러 냅니다.
- 배포본과 데스크톱 앱은 콘텐츠 보안 정책(CSP)으로 이 앱·구글 로그인·구글 글꼴 말고는 스크립트를 불러오거나 데이터를 보내지 못하게 막습니다. 데스크톱 앱은 이 컴퓨터 안(127.0.0.1)에서만 열리고, 카메라·마이크·위치 같은 권한은 모두 거절합니다.
- 소리 내어 읽기는 기기 안에서 읽는 목소리를 먼저 씁니다.
- AI 낭독을 켜면 읽을 원고 글이 구글(generativelanguage.googleapis.com)로 보내집니다. Gemini API 키는 이 기기에만 저장되고(원하면 창을 닫을 때까지만) 백업 파일·드라이브 동기화에 들어가지 않으며, 요청 주소가 아닌 머리글에 담아 보냅니다. 무료 등급 키로 보낸 글은 구글이 서비스 개선에 쓸 수 있습니다.
- 저장소에 키·토큰이 들어가지 않게 `npm run check:secrets`로 점검하고, 빌드할 때마다 자동으로 검사합니다. `.env` 파일은 올라가지 않습니다.

## 한글 파일에 대해
- .hwpx: 열기·저장 모두 됩니다. 저장한 파일은 OWPML 공식 스키마 검사를 통과합니다.
- .hwp(옛 형식): 열기만 됩니다(본문 글자, 표 안 글자 포함. 서식은 빠짐). 암호 걸린 문서·배포용 문서는 열 수 없습니다. 저장은 .hwpx로 하고, 필요하면 한글에서 ‘다른 이름으로 저장’으로 .hwp를 만드세요.
- Word(.docx): 열면 굵게·기울임·밑줄·제목·목록이 유지되고, 가운데 정렬·글자 색은 빠질 수 있습니다.

## Word .doc · PDF에 대해
- .doc(Word 97~2003): 열면 본문 글자를 가져옵니다(굵게 등 서식과 장 구분은 빠짐). 저장은 Word와 한글이 .doc로 그대로 여는 RTF 방식으로 합니다(굵게·기울임·밑줄·정렬·제목 유지).
- PDF: 글자를 꺼내 줄과 문단을 복원합니다. 쪽을 넘어가는 문단은 이어 붙이고, 쪽 번호는 뺍니다. 큰 글씨 줄은 장 제목으로 인식합니다. 스캔한 이미지 PDF는 글자가 없어 열 수 없고, 줄 끝에서 낱말이 잘린 자리에는 띄어쓰기가 하나 더 들어갈 수 있습니다.

## 데스크톱 앱 (Windows·macOS)
브라우저 없이 Word처럼 설치해서 쓰는 프로그램입니다. [최신 설치 파일 받기](https://github.com/lussion629-creator/SOSUL-CHANGJAK-PROGRAM/releases/latest) — 설치 파일을 실행하면 바탕 화면과 시작 메뉴에 ‘소설 워드프로세서’가 생깁니다.
- **자동 업데이트**: 켤 때와 6시간마다 새 버전을 확인합니다. Windows는 새 버전을 뒤에서 받아 두었다가 ‘지금 다시 시작’을 누르거나 앱을 끌 때 설치하고, macOS(서명 없는 앱)는 새 버전이 나왔다고 알려 주고 받는 곳을 엽니다. 도구 → 업데이트 확인으로 바로 확인할 수도 있습니다.
- 원고는 이 컴퓨터 안에 저장되고, 창을 닫을 때도 먼저 저장합니다.
- 파일을 오른쪽 클릭 → 연결 프로그램 → 소설 워드프로세서로 docx·hwp 등을 바로 열 수 있습니다.
- 구글 드라이브를 쓰려면 승인된 JavaScript 원본에 `http://localhost:47615`도 추가하세요.
```
npm run desktop    # 개발용으로 실행
npm run dist:win   # release/ 에 Windows 설치 파일
npm run dist:mac   # release/ 에 macOS 설치 파일
```
새 버전 내기: `package.json`의 `version`을 올려 main에 올리면 `.github/workflows/desktop.yml`이 Windows·macOS 설치 파일과 업데이트 정보(latest.yml)를 만들어 릴리스 `v<버전>`에 붙이고, 설치된 앱들이 그 릴리스를 보고 업데이트합니다.

## 실행·배포
```
npm install
npm run dev        # 개발 서버
npm run build      # dist/ → GitHub Pages 등 아무 정적 호스팅에 올리면 PWA로 동작
```
main 브랜치에 올리면 `.github/workflows/pages.yml`이 빌드해서 GitHub Pages에 자동으로 배포합니다.
